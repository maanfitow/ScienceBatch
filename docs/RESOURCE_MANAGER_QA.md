This document records selective CLI preparation and offline compilation, Linux native desktop checks, and headless/browser-mock checks. Results describe the tested Linux machine and fixture set; they do not establish cross-platform behavior.

## Direct MCP request-drop cancellation

Direct MCP operations now mark their shared worker cancellation flag if the request future is dropped, while normal completion disarms that behavior. The existing selective preparation supervisor owns the worker process and semaphore permit until cancellation is reaped. Focused Rust tests verified that aborting a started pending operation sets cancellation and that a completed operation does not. This is backend unit evidence; it does not replace a live MCP transport disconnect test for direct preparation.
